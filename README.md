# Journal Studio 内测版

Journal Studio 是一个手帐页面设计与绘制网页。你可以用画布记录日常、整理素材，并让 AI 按你的描述生成可预览、可继续编辑的页面设计。

## 在线体验

打开 [Journal Studio 内测网页](https://journal-studio-personal.1790770148.workers.dev/)。普通用户不需要安装程序，也不需要自己准备 AI Key；首次使用需要自己的坚果云账号和“应用密码”。请先阅读[内测用户使用指南](内测用户使用指南.md)。

## 内测须知

- 每位用户的数据保存在自己的坚果云 `JournalStudio` 文件夹中。应用不会把所有用户的数据集中存入 Journal Studio 的数据库。
- 登录时填写坚果云账号和专为 Journal Studio 创建的应用密码，不要填写坚果云主密码。连接期间，应用通过 HTTPS 将凭证交给 Worker，用于验证和访问该账号的 WebDAV；刷新网页后需要重新连接。
- AI 设计时，你输入的描述、必要的素材信息或预览图会经由 Cloudflare Worker 发送给硅基流动的 AI 服务。请勿上传密码、证件、私人聊天等敏感信息。
- 手动点击“保存”后，手帐内容会写入你自己的坚果云。切换设备前先保存，另一台设备打开网页并重新连接后刷新读取。
- 当前共享 AI 服务有每个坚果云账号每分钟 12 次、全站每分钟 60 次的限流。达到限额时稍后再试。限流是保护措施，不是严格的跨地区用量计费。
- AI 结果可能遗漏要求。应用前先检查预览；标记为“待调整”的草稿仍可能有未满足项。

## 出问题时

提交 GitHub Issue 时请写明：浏览器和设备、操作步骤、看到的提示、发生时间。截图前请遮住姓名、邮箱、坚果云文件内容和图片中的私人信息。

**不要在 Issue、讨论区或截图中发送坚果云应用密码、坚果云主密码、API Key、手帐 JSON 或未打码的私人素材。**

## 仓库内容

- `worker/`：网页、Worker API 和坚果云客户端源代码。
- `scripts/`：构建脚本和不需要真实账号的 AI 链路回归检查。
- `内测用户使用指南.md`：面向内测用户的操作说明。

本仓库是网页源代码。普通内测用户只需访问上面的在线网页；GitHub Desktop 发布代码不会自动更新 Cloudflare 上的网页。

当前仓库尚未附带开源许可证。没有许可证时，大家可以查看代码并使用在线内测网页，但不能据此假设可以复制、修改或再发布代码。若要开放代码复用，请先由项目维护者选择并添加许可证。
